Ecosystem Projects

Every project deployed through the Ecosystem Deployment Console runs on its own sovereign Datachain Rope node — predictive maintenance fleets, environmental monitoring networks, sentient-environment deployments. Regulators and investors access each project's live, on-chain-anchored data directly from the project's node: dcscan lists the projects, but the data stream never passes through an intermediary. Access scope, duration, and pricing are controlled by each project owner via cryptographic grants.

Launch the Deployment Console Directory API

The hosted console at console.datachain.network signs you in with your wallet (EIP-191) and includes a full sandbox mode with synthetic scenario data — no KYB, no cost. Sovereign production deployments can also self-host the same open-source rope-edc binary on their own node and register it in this directory.

Direct data access for regulators & investors

1

Discover a project below and open its detail card — it lists the public access offers (scope, delivery, pricing) published by the project owner.

2

Request a grant from the project owner. Regulator and public grants pass through an on-chain Timelock before activation.

3

Receive an API key minted against the grant — scoped to specific assets, facets (readings / diagnoses / approvals), and an expiry.

4

Consume directly from the project's own node: REST, live SSE stream, or AI-narrated analytics. Every reading traces to an anchored knot.
