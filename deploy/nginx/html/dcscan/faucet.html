How the testnet faucet works
  • Paste any EVM address at faucet.datachain.network to receive 100 xFAT.
  • Rate limits: 1 drip / address / 24h and 3 drips / IP / 24h, plus a 2 req/s edge rate limit.
  • Public testnet RPC enforces the same Phase-1 destructive-method gate as mainnet - only signed writes with the correct chain_id=271829 tag are accepted.
  • This testnet may be wiped at any time. Do not depend on its state; treat every deploy as ephemeral.
  • A chainlist.org listing is in review at ethereum-lists/chains PR #8658. Until it merges, use the manual add-to-wallet button above.
No faucet on mainnet
Chain 271828 Production

Datachain Rope mainnet (chainId 271828) is a live production network. DC FAT is a real, economically-valued asset - not a testnet token. There is no faucet here by design.

  • DC FAT has real market value - see the supply reconciliation page for the live circulating figure and treasury holdings.
  • A page that dispensed free mainnet FAT on request would be a direct treasury-drain / abuse vector, so this explorer does not implement or fake one.
  • To get FAT for gas, acquire it on DCSwap or bridge it from a supported chain.
  • To build and test contracts without touching real value, use the testnet faucet above (chainId 271829). For a mainnet deploy, use a small real amount of FAT against https://erpc.datachain.network - see the API docs.
